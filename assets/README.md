# Settings header artwork

settings-header.svg is the editable vector composition; settings-header.png is
its transparent export for Homebridge's standard Markdown schema header.

- Homebridge: official homebridge-color-round.svg from
  https://github.com/homebridge/branding/tree/latest/logos
- Advantage Air: original 16 logo paths extracted from page 27 of the official
  MyAir user manual (PDF SHA-256
  69a706fd0bd8205dfa61dac9765be34973cf77ca1228aff6086a09e5f39ca85f):
  https://www.advantageair.com.au/wp-content/uploads/2021/03/MyAir-and-MyAir-User-Manual-v4.1.pdf
- The Advantage Air paths use #005DAB, matching the official website wordmark.
  Path geometry is unchanged. No tracing, redrawing or font substitution.

The logos retain their respective owners' branding. This composition identifies
the integration; it does not imply endorsement.

The schema references the PNG on v4-beta, so deleting a feature branch will not
break the header. Before merge, the disposable UI fixture substitutes the local
PNG for that URL. The public URL becomes available when this asset is merged.
